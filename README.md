# Шашки в браузере

Минимальная игра для двух игроков на одном устройстве: HTML, CSS и обычный
JavaScript. Сборщик, установка зависимостей и сервер для самой игры не нужны.
Интерфейс на русском языке, управление мышью, касанием или клавиатурой.

## Запуск

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив либо:

   ```sh
   git clone https://github.com/legalnotop-tech/limba.git
   cd limba
   ```

2. Откройте `index.html` в современном браузере. Он работает прямо с диска
   (`file://`): внешних ресурсов, `fetch` и ES-модулей нет.
3. Выберите белую шашку, затем одну из подсвеченных клеток. Далее играйте за
   чёрных. Кнопка **«Новая игра»** сбрасывает доску и возвращает ход белым.

При необходимости можно запустить обычный статический сервер из папки проекта:

```sh
python3 -m http.server 8000
```

Откройте <http://localhost:8000>. Остановка сервера: `Ctrl+C`.
В Windows команда Python может называться `py -m http.server 8000`.
Эти четыре файла также можно разместить на любом статическом хостинге.

| Файл | Назначение |

| `index.html` | Разметка, состояние игры, кнопка сброса и правила |

| `README.md` | Инструкции запуска и описание каркаса |

## Правила

- По 12 шашек у каждого игрока на тёмных клетках трёх начальных рядов.
  Белые расположены снизу и ходят первыми.
- Обычные шашки ходят на одну свободную клетку по диагонали вперёд,
  а бьют прыжком через соседнюю шашку соперника вперёд или назад.
- Любое доступное взятие обязательно: простые ходы запрещены для всех
  шашек игрока, пока существует взятие.
- Если после взятия можно бить ещё, серия продолжается той же шашкой.
  Игрок меняется только после завершения серии. При нескольких вариантах
  можно выбрать любой; брать максимальное число шашек не требуется.
- При достижении последнего ряда шашка сразу становится дамкой, в том числе
  в середине серии. Дамка ходит на любое свободное расстояние по диагонали
  и бьёт одну шашку соперника с выбором свободной клетки за ней.
- Взятые шашки показаны полупрозрачно до конца серии, продолжают перекрывать
  свои клетки и не могут быть взяты повторно. После серии они удаляются.
- Победа определяется автоматически, если соперник остался без шашек
  или без легальных ходов.

Реализованы базовые правила русских шашек. Это каркас: автоматические ничьи
по повторению позиции или числу ходов, бот, сетевой режим, история ходов и
сохранение партии пока не реализованы. Для новой партии при ничейной позиции
используйте **«Новая игра»**.

## Проверка без зависимостей

Для проверки синтаксиса при установленном Node.js:

```sh
node --check script.js
```

Движок отделён от интерфейса и доступен в Node.js через `require('./script.js')`.
Например, проверка стартовой позиции и первого хода:

```sh
node -e "const assert = require('node:assert/strict'); const g = require('./script.js'); const s = g.createGame(); const moves = g.getLegalMoves(s); assert.equal(moves.length, 7); const next = g.playMove(s, moves[0].from, moves[0].to); assert.equal(next.currentPlayer, 'black'); console.log('OK');"
```

В браузере проверьте 64 клетки и по 12 шашек, подсветку разрешённых ходов,
чередование сторон, обязательное взятие и сброс кнопкой **«Новая игра»**.
Для тестирования особых позиций используйте API движка:
`createGame()`, `getLegalMoves(state)` и `playMove(state, from, to)`.
Недопустимый ход возвращает `null`; допустимый возвращает новое состояние,
не изменяя предыдущее.
